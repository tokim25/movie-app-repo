## Known limitation: `full` description text is not updated by this script

Confirmed on both this batch's upgrades (e.g. #42 Peter Pan) and the first run's (e.g.
#546 Snow Day): for every fallback/approximate-to-real `ca` upgrade, the movie's `full`
description text still reads like the old fallback -- e.g. "Common Sense Media has not
reviewed this..." -- even though `ca` and `flags` now reflect the real CSM data. This
script only ever touches `ca`, `flags`, `csmRecheckedAt`, and `csmRecheckVersion`; it
never rewrites prose. The content filtering itself is correct either way (it reads `ca`
and `flags`, not `full`), but a parent reading the description for one of these 23 movies
will see stale, self-contradicting text. Rewriting `full` for these 23 titles from each
entry's CSM summary text is a reasonable follow-up, but is a separate, judgment-carrying
editorial pass this script deliberately did not attempt.
